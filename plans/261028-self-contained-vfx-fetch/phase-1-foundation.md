## Goal

Everything two or more lanes touch, plus the contract (plan.md `## Contract`, id `vfx-bytes/1`) as executable code, is on a committed, green base BEFORE any lane spawns. Lanes treat all of the above as READ-ONLY.

## Steps

1. Preconditions (read-only): `git status` clean; `podman exec vfx-pg pg_isready -U vfx -d vfxcloud`; record `SELECT name FROM schema_migrations ORDER BY 1` (expect 001-009). DO NOT run anything that reaches `migrate()` against the live DB in this phase.
2. Test harness: `scripts/accept/lib-testdb.sh` (functions `testdb_create <lane>` -> `createdb vfxcloud_test_<lane>` through `podman exec vfx-pg createdb -U vfx`, exports `DATABASE_URL`, `DATA_DIR=$(mktemp -d)`, trap drops both) and `with-testdb.sh <lane> <cmd...>`, which ALWAYS runs `node scripts/accept/migrate-testdb.ts` (calls `migrate()` on the scratch DB) before the wrapped command: measured by the correctness review, `node --test server/src/*.test.ts` on an empty DB fails 11 tests by race because only `magenta.test.ts` and `preview-gif.test.ts` call `migrate()`; also note `recolor-service.test.ts` and `facet-search.test.ts` SKIP without a corpus, so a green there on a scratch DB proves nothing (the accept scripts list them as skipped, never as passed). `server/src/test-fixtures/scratch-db.ts` exports `assertScratchDb()`: throws unless the database name in `config.databaseUrl` matches `/_test(_|$)/` AND `config.dataDir` is not the repo `data/` dir (`recolor-service.test.ts:17` and `publish-derived.test.ts:24` `fs.rm` under it); every NEW DB-backed test calls it first, so a bare run against `vfxcloud` fails loudly instead of writing live rows.
3. Migration `010_asset_blobs.sql` exactly per plan.md C1/C2/C9: swap `resource_visibility_check` and `asset_visibility_check` to include `studio-only` (`DROP CONSTRAINT IF EXISTS` then `ADD`, same pattern as 007), `CREATE TABLE IF NOT EXISTS` for `asset_blob`, `asset_file` (+ indexes on `asset_sha256`, `meta_sha256`, GIN on `refs`), `preview_render` (with the cause-enum CHECK of plan.md C9 so an invented cause is rejected). Additive, no data rewrite. Confirm the two constraint names against `pg_constraint` on the scratch DB and in a test.
4. `config.ts`: `blobDir` (`path.join(dataDir,'blobs')`), `blobMaxBytes` (`VFX_BLOB_MAX_BYTES`), `bundleMaxFiles` (`VFX_BUNDLE_MAX_FILES`), `blobAllowAnon` (`VFX_BLOB_ALLOW_ANON === '1'`). `errors.ts`: code union gains `too_large | forbidden`, optional `details`.

6. `bundle-contract.ts`: zod schemas + TS types for `AssetFileInput`, `BundleFile`, `Bundle`, `ErrorEnvelope`, `RenderFailureFile` exactly as plan.md C3/C4/C5/C9, plus `KIND_RANK`, `TEXT_KINDS`, `kindOfPath(path)`. `test-fixtures/reroot-cases.json` = table of `{target_path, root, expected}` cases for the pure `reroot` of plan.md C4 (shared by lanes F and C, which never create it); `test-fixtures/bundle-sample.json` = a valid `Bundle` with one prefab, two materials (one `urp`), a texture, a shader, one `requires`, one `unresolved: []`.
7. `unity-refs.ts`: `scanRefs(bytes): string[]` with exactly the three patterns P1/P2/P3 of plan.md C2 (YAML `guid:`, asmdef `GUID:`, Shader Graph escaped-JSON `\"guid\":\"...\"`), distinct, lower-case, own guid excluded by the caller, ignores fileID-only refs, binary-safe; `kindOfPath` maps `.asmref` to `asmdef`; constants `BUILTIN_NAMES` (`Unity default resources`, `Unity extra resources`); `isBuiltinGuid(guid)` (reads `rules.assets.builtinGuidPattern` from `seed/graph/rules`), `loadPackageGuids()` (reads `unity-package-guids.json`, validates shape `{version:1, entries:{<guid>:{kind:'package'|'builtin',name,package,version}}}`). Skeleton JSON `{"version":1,"entries":{}}`; lane P is its only writer from here on.
8. `seed/extract/source.ts` (+ tests): extend `PackageSource` with `files(want)` yielding `{guid,path,data,meta:Buffer|null}` (tar: `<guid>/asset.meta`; folder: `<file>.meta`), `copiesOf(guid)` -> `[{origin,sha256}]` for every kind and every source type (D16), and `folderSetSource(roots,prefix,{preferCopy?:(guid,bytes)=>boolean})` implementing decision D8 (first copy for which `preferCopy` is true, else the first). Existing behaviour unchanged when `preferCopy` is absent.
9. `packs.json`: studio-game-vfx gets `"visibility":"studio-only"`; every pack gets `"bytes": true` (consumed by the uploader); no other field changes.
10. `package.json`: scripts `upload:blobs` (`node seed/upload-blobs.ts`), `verify:closure` (`node seed/verify-closure.ts`), `ingest:failures` (`node seed/preview-failures-ingest.ts`), `package:guids` (`node seed/extract/package-guids.ts`), `test` glob extended to `seed/*.test.ts seed/upload/*.test.ts scripts/*.test.mjs scripts/*.test.ts` (keep every existing entry; `seed/extract/*.test.ts` is already there). 11. `LICENSES.md`: rewrite rules 3 and 5 and the `studio-internal` row: bytes of purchased packs and studio assets are stored in the studio-internal cloud (owner decision 2026-10-28), served only with the API key, `visibility` never `global`, `ai_training=false`, recipe payload still metadata only; drop the "`studio-only` needs a migration" note. `README.md`: new section "Bytes and bundle API" linking to plan.md C1-C8 (human copy, no duplicate field lists beyond a table of routes).

## Tests that must go RED when the guarded rule is removed (reviewer mutation-proves each)

- `bundle-contract.test.ts`: insert into `asset_file` with `visibility='global'` fails; with `ai_training=true` fails; bad guid/sha shape fails; `variant='urp'` with non-material is rejected by the schema; the sample fixture parses and an extra/missing key fails.
- `license.test.ts`: `blobLicenseProblem` refuses `unknown`, `restricted`, `cc0`+`global` is allowed only if not proprietary, `asset-store-eula`+`global` refused, `studio-internal`+`studio-only` accepted.
- `unity-refs.test.ts`: refs found in a real prefab/material/asmdef excerpt (fixture) AND in a trimmed real `.shadergraph` (escaped-JSON form, a `m_SerializedTexture` and a `m_SerializedSubGraph`), the real self-reference case (`BalloonRelease.prefab` `m_CorrespondingSourceObject` carrying its own guid: not in `refs`), builtin `0000000000000000f000000000000000` classified builtin, own guid excluded, binary input yields `[]`.
- `source.test.ts`: `preferCopy` picks the 2nd game's copy when only it contains a ParticleSystem; absent option keeps first-wins; `files()` returns `.meta` bytes for tar and folder.

## Rollback

Code: `git revert` the phase commits. DB (only if phase 9 already migrated): restore the phase-9 backup (`pg_restore --clean --if-exists -d vfxcloud <dump>` inside the container) or run, in order, `BEGIN; DROP TABLE preview_render, asset_file, asset_blob; UPDATE resource SET visibility='project' WHERE visibility='studio-only'; UPDATE asset SET visibility='project' WHERE visibility='studio-only'; ALTER TABLE resource DROP CONSTRAINT resource_visibility_check, ADD CONSTRAINT resource_visibility_check CHECK (visibility IN ('project','team','global')); (same for asset); DELETE FROM schema_migrations WHERE name='010_asset_blobs.sql'; COMMIT;` then `rm -rf data/blobs`. The down SQL lives only in this file (a `.sql` in the migrations dir would be run by `migrate()`).
